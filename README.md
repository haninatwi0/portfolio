## Sobre o Projeto

O portfólio foi desenvolvido para reunir meus principais projetos em um único lugar, facilitando o acesso aos códigos-fonte, às tecnologias utilizadas e às informações sobre minha formação acadêmica.

A interface foi projetada para oferecer uma navegação simples, organizada e responsiva, adaptando-se a diferentes tamanhos de tela.

## Projetos em Destaque

### TaskFlow

Aplicação web para gerenciamento de tarefas, desenvolvida com Flask. Possui funcionalidades de autenticação de usuários, criação e organização de tarefas e acompanhamento de atividades.

**Tecnologias:** Python, Flask, SQLite, SQLAlchemy, HTML e CSS.

### Sistema de Consultas Mobile

Aplicação mobile voltada ao gerenciamento de consultas, desenvolvida com React Native, Expo e TypeScript, integrada a um projeto de backend.

**Tecnologias:** React Native, Expo, TypeScript e desenvolvimento de APIs.

### Programação Orientada a Objetos

Projetos acadêmicos desenvolvidos em Java para praticar os princípios da programação orientada a objetos, incluindo encapsulamento, organização de classes e aplicação de regras de negócio.

**Tecnologias:** Java e POO.

### Análise de Dados — Olist

Projeto acadêmico de análise de dados utilizando informações do comércio eletrônico brasileiro, com foco na exploração dos dados e na identificação de padrões relevantes.

**Tecnologias:** Python, Jupyter Notebook e análise de dados.

### Visualização de Dados — OpenPowerlifting

Projeto de exploração e visualização de dados relacionados ao levantamento de peso, utilizando técnicas de análise e representação gráfica.

**Tecnologias:** Python, Jupyter Notebook e visualização de dados.

## Execução Local

Para visualizar o portfólio em seu computador:

1. Clone este repositório:

   ```bash
   git clone https://github.com/haninatwi0/portfolio.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd portfolio
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.
